# Веб-платформа онлайн-курса «Web разработчик» с применением ИИ

Клиент-серверное веб-приложение для дистанционного обучения с автоматической декомпозицией учебных тем, генерацией тестов, интерактивной проверкой кода и контекстным ИИ-наставником.

Разработано в рамках курсовой работы по дисциплине **«Серверное программирование»** (Костанайский региональный университет им. А. Байтұрсынұлы).

---

## 🌟 Основные возможности

1. **Реальная система аутентификации (Supabase Auth)**:
   - Разделение прав доступа на две роли: **«Преподаватель» (`teacher`)** и **«Студент» (`student`)**.
   - Регистрация, вход по паролю, получение сессионных JWT-токенов (`access_token`, `refresh_token`), серверная защита маршрутов через middleware `requireRole`.
   - Отсутствие фиктивных переключателей — каждый пользователь входит под своей учётной записью.

2. **Двухэтапная ИИ-генерация курса преподавателем (Claude API)**:
   - **Без захардкоженных курсов**: преподаватель вводит любую произвольную тему (например, *«Разработка REST API на Node.js и баз данных PostgreSQL с авторизацией JWT»*), уровень сложности и количество блоков.
   - **Этап 1 (План)**: Claude API декомпозирует тему на последовательные учебные блоки с формулировкой целей. Преподаватель может рецензировать и редактировать план.
   - **Этап 2 (Контент)**: ИИ генерирует для каждого блока структурированный конспект, ключевые концепции, практический пример кода, комплект тестовых вопросов и практическое задание с критериями оценки.
   - **Публикация курса**: при публикации генерируется уникальный **6-значный инвайт-код** (например, `7K2B9X`) для передачи студентам.

3. **Последовательное обучение студента (Sequential Progression)**:
   - Запись на курс по 6-значному коду приглашения.
   - Начальный блок курса открыт сразу, последующие блоки имеют статус `🔒 Заблокирован`.
   - Следующий блок разблокируется **строго после успешной сдачи теста (не менее 70 %)** и **зачёта практического задания**.

4. **Интерактивное рабочее место студента**:
   - Чтение теоретического материала с подсветкой синтаксиса примеров кода.
   - Прохождение контрольного тестирования (правильные ответы скрыты на сервере, расчёт баллов по формуле $S_{quiz} = \text{round}(K_{correct} / N_{total} \times 100)$).
   - Встроенный редактор кода для практических задач с автоматической рецензией от Claude AI.
   - Контекстный **ИИ-наставник** с педагогическими ограничениями: наставник объясняет причину ошибки и подсказывает следующий шаг, категорически запрещая выдавать готовое решение.

5. **Кабинет преподавателя и аналитика**:
   - Мониторинг успеваемости всех записавшихся студентов.
   - Отображение статуса каждого блока (пройден / в процессе / заблокирован) и средних баллов.

## 🏗️ Архитектура и стек технологий

| Компонент | Технология / Модуль | Назначение |
|---|---|---|
| **Сервер приложений** | Node.js 20+, Express 5 (`src/server.js`) | REST API, обработка запросов, бессерверный запуск на Vercel |
| **Аутентификация** | Supabase Auth, JWT (`src/auth.js`) | Регистрация, вход, проверка токенов `requireRole` |
| **Искусственный интеллект** | Anthropic SDK (`src/ai.js`) | Claude API (`claude-haiku-5-5`), генерация блоков, ревью кода, подсказки |
| **Бизнес-логика** | Детерминированные функции (`src/logic.js`) | Расчёт баллов тестов, вычисление прогресса, инвайт-коды, XML-экранирование |
| **База данных** | PostgreSQL 15 / Supabase Cloud (`src/supabase.js`) | 9 реляционных таблиц, каскадные связи, `service_role` ключ |
| **Клиентский интерфейс** | HTML5, CSS Grid/Flexbox, Vanilla JS (`public/index.html`) | Адаптивное одностраничное приложение (SPA) |
| **Тестирование** | Vitest (`tests/logic.test.js`) | Автоматическое тестирование алгоритмов (100% pass) |

## 🗄️ Структура базы данных (Supabase PostgreSQL)

Схема базы данных содержится в файле `supabase/schema.sql` и состоит из 9 таблиц:

1. `profiles` — профили пользователей с ролями (`teacher` или `student`), связаны с `auth.users`;
2. `courses` — паспорта созданных курсов со статусом (`draft`/`published`) и инвайт-кодом;
3. `course_blocks` — учебные блоки курса с конспектом, примерами кода и ключевыми понятиями;
4. `quiz_questions` — тестовые вопросы со скрытым полем `correct_index`;
5. `practice_tasks` — практические задания с инструкцией, шаблоном кода и критериями;
6. `enrollments` — записи студентов на курсы по инвайт-коду;
7. `quiz_attempts` — попытки прохождения тестов с расчётом баллов и статусом зачёта;
8. `practice_submissions` — сданный студентом код с рецензиями и оценками ИИ;
9. `tutor_messages` — журнал диалогов с ИИ-наставником.

## 🚀 Развёртывание на Vercel через Git

Проект полностью оптимизирован для бессерверного развёртывания на платформе **Vercel**:

1. Загрузите проект в репозиторий GitHub:
   ```bash
   git push origin main
   ```
2. Откройте [Vercel Dashboard](https://vercel.com/) и нажмите **Add New Project**.
3. Выберите репозиторий GitHub.
4. В разделе **Environment Variables** укажите переменные:
   - `SUPABASE_URL` — URL вашего проекта в Supabase (`https://<project-ref>.supabase.co`);
   - `SUPABASE_SERVICE_ROLE_KEY` — ключ `service_role` из настроек API в Supabase;
   - `ANTHROPIC_API_KEY` — API-ключ от Anthropic (`sk-ant-...`);
   - `ANTHROPIC_MODEL` — используемая модель (рекомендуется `claude-haiku-5-5`).
5. Нажмите **Deploy**. Vercel автоматически соберет проект и предоставит публичный HTTPS-адрес.

## 💻 Локальный запуск

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` на основе `.env.example` и укажите ключи доступа:
   ```env
   PORT=3000
   SUPABASE_URL=https://<project-ref>.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
   ANTHROPIC_API_KEY=sk-ant-your-key
   ANTHROPIC_MODEL=claude-haiku-5-5
   ```
3. Инициализируйте таблицы в Supabase:
   Скопируйте содержимое файла `supabase/schema.sql` и выполните его в **SQL Editor** панели Supabase.
4. Запустите сервер:
   ```bash
   npm start
   ```
5. Откройте в браузере: [http://localhost:3000](http://localhost:3000).
